DATA FEASIBILITY TEST RESULTS


============================================================
SETLIST.FM — 50-STATE COVERAGE TEST
============================================================

Purpose:
Determine whether Setlist.fm contains documented setlist data
for all 50 U.S. states.

Results:
- 50 states tested
- 50 states returned data
- 0 states returned no data
- Alaska initially returned HTTP 429 due to rate limiting
- Alaska was retested separately and returned HTTP 200
- Alaska returned 2,191 setlists

Conclusion:
Setlist.fm has documented setlist data for all 50 U.S. states.

The earlier concern that the source only contained data for
approximately 30 states does not appear to be a geographic
coverage limitation of Setlist.fm.

Geographic coverage therefore appears viable for the
Music Across America portion of the project.

Important limitation:
The existence of data in all 50 states does not mean coverage is
equally complete across states or across historical periods.
Setlist.fm represents documented setlists rather than a complete
census of every concert that occurred.


============================================================
MUSICBRAINZ — GENRE/CATEGORY COVERAGE TEST
============================================================

Purpose:
Determine how often artists found through Setlist.fm have usable
genre/category information available through MusicBrainz.

Sample:
- 200 unique artists collected from Setlist.fm

Final results:
- 200 artists sampled
- 195 successful MusicBrainz responses
- 5 API errors after retries
- 153 artists had formal genre data
- 0 artists had tags but no formal genre
- 42 artists had neither genre nor tags

Coverage:
- Formal genre coverage among successful responses: 78.5%
- Genre-or-tag coverage among successful responses: 78.5%
- True missing metadata among successful responses: 21.5%
- API error rate after retries: 2.5%

Examples with no genre or tags:
- DJ Moon
- Band of Silver
- Armlock
- Charloux
- Dark Chapel
- Kevin Atwater
- Chad Gray
- Rum Jungle
- Stephen Dawes
- Mismiths

Artists that still failed after retries:
- Blue Snaggletooth
- Jimmie Vaughan & The Tilt-A-Whirl Band
- Incantation
- Miki Fiki
- BABYMETAL

Conclusion:
MusicBrainz provides usable formal genre information for roughly
4 out of 5 artists in this sample.

Missing category information is therefore a real data-quality
issue, but it does not affect the majority of artists.

The retry test also showed that many temporary MusicBrainz 503
errors can be recovered. After retry handling, only 5 of the
200 sampled artists still failed, producing a final API error
rate of 2.5%.

This distinction is important:
- A MusicBrainz API failure does not mean an artist has no genre.
- A successful response with zero genres and zero tags represents
  genuinely missing metadata in MusicBrainz.

Next step:
Test a secondary enrichment source for the 42 artists that had
successful MusicBrainz responses but returned neither genre nor tags.

The goal is to determine whether a fallback data source can improve
genre coverage enough to make genre a reliable interactive filter
for the Music Across America dashboard.

============================================================
WIKIDATA — EXACT MBID GENRE RESCUE TEST
============================================================

Purpose:
Determine whether Wikidata can recover genre information for the
42 artists that had successful MusicBrainz responses but returned
neither genre nor tags.

Method:
Each artist was matched to Wikidata using the artist's exact
MusicBrainz ID (MBID), avoiding name-based matching ambiguity.

Results:
- 42 artists tested
- 3 artists had genre information recovered
- 38 artists still had no genre information
- 1 Wikidata request returned an HTTP 502 error
- Rescue rate: 7.1%

Successful rescues:
- Chad Gray: alternative metal, groove metal, nu metal
- Alice Bag: rock music
- Mike D: hardcore punk, hip-hop, alternative hip-hop, rap rock

Combined genre coverage:
- MusicBrainz supplied genre data for 153 of 195 successful responses.
- Wikidata recovered genre data for 3 additional artists.
- Combined known genre coverage: 156 of 195 artists, or 80.0%.
- 38 of 195 artists remain without genre metadata, excluding the
  single Wikidata request that failed.

Conclusion:
Wikidata provides some additional genre information, but the
improvement is small. Exact-MBID enrichment increased usable genre
coverage from 78.5% to 80.0% in this sample.

The 7.1% rescue rate among MusicBrainz metadata gaps does not appear
large enough to justify relying on Wikidata as a comprehensive genre
fallback.

Genre can still be used analytically, but missing genre values should
be handled explicitly rather than assuming complete classification.

============================================================
LAST.FM — CLEAN GENRE RESCUE TEST
============================================================

Purpose:
Determine whether Last.fm can recover usable genre information for
the 42 artists that had successful MusicBrainz responses but returned
neither genre nor tags.

Method:
Last.fm artist tags were requested using the artist's MusicBrainz ID
(MBID) when available, with artist-name lookup as a fallback.

Because Last.fm tags are user-generated and may contain non-genre
information, returned tags were filtered through an approved genre
vocabulary. This removed artist names, locations, descriptive labels,
and other non-genre tags before evaluating coverage.

Results:
- 42 artists tested
- 31 artists had usable genre information recovered
- 11 artists remained without a valid genre
- 0 API errors
- Clean rescue rate: 73.8%

Examples of successful clean rescues:
- DJ Moon: psytrance, electro, goa, breaks
- Band of Silver: indie, electropop, indie pop, electronic
- Armlock: lo-fi, indie rock, bedroom pop, indie
- Midnight Generation: disco, dance, funk, electronic, electronica
- Devil's Cut: alternative metal, metal
- Squint: hardcore, hardcore punk, pop punk
- Jasmine Cain: hard rock, rock
- Winona Fighter: pop punk, punk
- Drew & Ellie Holcomb: folk

Still missing after Last.fm:
- Chad Gray
- Mismiths
- Boy Seeking Band
- doug.
- Tom Siletto
- Hope Darling
- The Rush Tribute Project
- Yacht Rock Revue
- Zach John King
- The Marble Creek Loops
- The Jess Novak Band

Conclusion:
Last.fm substantially improved genre coverage for artists missing
genre metadata in MusicBrainz. After filtering user-generated tags
through an approved genre vocabulary, Last.fm recovered usable genre
information for 31 of the 42 missing artists, a 73.8% clean rescue
rate.

MusicBrainz classified 153 of the 195 artists with successful
responses. Adding the 31 clean Last.fm rescues increases usable genre
coverage to 184 of 195 artists, or 94.4%.

Wikidata additionally recovered Chad Gray, who remained unresolved
by Last.fm. Using the three sources together therefore provides
genre information for 185 of 195 artists, or 94.9% of the successful
MusicBrainz sample.

The recommended enrichment hierarchy is:

1. MusicBrainz formal genre data
2. Last.fm cleaned genre tags
3. Wikidata exact-MBID genre fallback
4. Unknown when no source provides usable genre metadata

============================================================
DISCOGS — VERIFIED GENRE RESCUE TEST
============================================================

Purpose:
Determine whether Discogs could recover genre information for the
10 artists that remained unresolved after MusicBrainz, cleaned
Last.fm enrichment, and Wikidata.

Method:
Because Discogs search results can include unrelated artists with
similar names, artist identity was verified before genre information
was accepted.

The test first searched Discogs specifically for artist records.
A result was accepted only when the normalized Discogs artist name
matched the target artist name. Genre and style information was then
collected only from releases associated with that verified Discogs
artist ID.

Results:
- 10 artists tested
- 7 verified genre rescues
- 3 artists had no verified Discogs artist match
- 0 verified artists lacked genre data
- 0 API errors
- Verified rescue rate: 70.0%

Successful verified rescues:
- Mismiths: Rock; Punk, Post-Punk, Alternative Rock, Horror Rock
- Tom Siletto: Hip Hop; Boom Bap
- Hope Darling: Rock, Pop; Industrial, Goth Rock
- The Rush Tribute Project: Rock; Prog Rock
- Yacht Rock Revue: Rock, Funk / Soul, Pop; Pop Rock, AOR,
  Power Pop, Soft Rock
- Zach John King: Folk, World, & Country; Country
- The Jess Novak Band: Rock

Still unresolved:
- Boy Seeking Band
- doug.
- The Marble Creek Loops

Conclusion:
Discogs provided substantial additional coverage for artists that
remained unresolved after the first three metadata sources.

An initial name-based Discogs test produced apparent matches for
9 of 10 artists, but inspection showed that several results combined
genre information from unrelated releases. Those results were not
accepted.

After adding artist-identity verification, Discogs produced 7
verified genre rescues. This demonstrates the importance of entity
matching when combining data from multiple music databases.

The verified Discogs results increase total usable genre coverage
from 185 of 195 artists to 192 of 195 artists, or 98.5%.

Only 3 of the 195 artists with successful MusicBrainz responses
remain without usable genre metadata after enrichment.
