DATA FEASIBILITY TEST RESULTS

SETLIST.FM — 50-STATE COVERAGE TEST

Purpose:
Determine whether Setlist.fm contains documented setlist data
for all 50 U.S. states.

Results:
- 50 states tested
- 50 states returned data
- 0 states returned no data
- Alaska initially returned HTTP 429 due to rate limiting
- Alaska was retested separately and returned HTTP 200
- Alaska returned 2,191 setlists

Conclusion:
Setlist.fm has documented setlist data for all 50 U.S. states.
The earlier concern that the source only contained data for
approximately 30 states does not appear to be a geographic
coverage limitation of Setlist.fm.


MUSICBRAINZ — GENRE/CATEGORY COVERAGE TEST

Purpose:
Determine how often artists found through Setlist.fm have usable
genre/category information available through MusicBrainz.

Sample:
- 200 unique artists collected from Setlist.fm

Status:
- Test reached artist 165 before the connection was reset
- Some MusicBrainz requests returned HTTP 503 errors
- One request returned HTTP 404
- These API errors are being treated separately from artists that
  successfully returned no genre/category data

Preliminary results:
- 135 successful MusicBrainz responses before the connection failure
- 110 successful responses contained formal genre data
- 25 successful responses contained neither genre nor tags
- Preliminary formal genre coverage among successful responses:
  approximately 81.5%

Important:
These are preliminary results. The test needs to be rerun with
retry/error handling before a final genre-coverage percentage is reported.

Preliminary conclusion:
The missing-category issue is real, but the initial test suggests
that most successful MusicBrainz responses do contain genre information.
Temporary API/service errors are also contributing to apparent missing data.
